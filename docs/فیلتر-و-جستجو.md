# پنل فیلتر و جستجوی فروشگاه

افزونهٔ `plugins/parsian-shop-filters` به صفحهٔ فروشگاه و بایگانی هر دسته‌بندی محصول،
نوار جستجو و پنل فیلتر اضافه می‌کند.

## نصب

۱. پوشهٔ `plugins/parsian-shop-filters` را در `wp-content/plugins/` سایت کپی کنید.
۲. پیشخوان ← افزونه‌ها ← «پارسیان کارتن — فیلتر و جستجوی فروشگاه» ← فعال‌سازی.
۳. تنظیمات: پیشخوان ← محصولات ← **فیلترهای فروشگاه**.

روی داکر لوکال، `wordpress/` به کانتینر mount شده است؛ پس کافی است پوشه را داخل
`wordpress/wp-content/plugins/` بگذارید.

## چه چیزهایی فیلتر می‌شوند

| فیلتر | پارامتر آدرس | توضیح |
|---|---|---|
| جستجوی متنی | `psf_q` | جستجو **درون همان دسته‌بندی**، نه کل سایت |
| دسته‌بندی | `psf_cat[]` | در فروشگاه دسته‌های سطح اول، در یک دسته زیردسته‌هایش |
| بازهٔ قیمت | `psf_min` و `psf_max` | **به تومان** |
| ویژگی‌ها | `psf_attr_<نام>[]` | هر ویژگی سراسری ووکامرس (سایز، تعداد لایه، نوع چاپ و…) |
| فقط موجود | `psf_stock=1` | `_stock_status = instock` |
| فقط حراج | `psf_sale=1` | محصولات دارای قیمت حراج فعال |

مرتب‌سازی از خود ووکامرس استفاده می‌کند (`orderby`) و هنگام جستجو گزینهٔ
«مرتبط‌ترین با جستجو» به فهرست اضافه می‌شود.

## نکتهٔ مهم: واحد قیمت

قالب `cartonpak` قیمت‌ها را **به ریال** در دیتابیس نگه می‌دارد و هنگام نمایش بر ۱۰
تقسیم می‌کند. پنل فیلتر همین را در نظر می‌گیرد: عددی که کاربر می‌بیند و در آدرس
صفحه ثبت می‌شود **تومان** است و فقط هنگام ساخت پرس‌وجو به ریال تبدیل می‌شود.

تشخیص واحد خودکار است (وجود تابع `cartonpak_rial_to_toman`). اگر روزی قالب عوض شد:

```php
add_filter( 'psf_price_divisor', function () {
	return 1; // قیمت دیتابیس همان چیزی است که نمایش داده می‌شود
} );
```

## رفتار بدون جاوااسکریپت

پنل یک فرم `GET` ساده است؛ بدون جاوااسکریپت هم کامل کار می‌کند (فقط باید دکمهٔ
«اعمال فیلتر» زده شود). با جاوااسکریپت:

- شبکهٔ محصولات بدون بارگذاری دوبارهٔ صفحه به‌روز می‌شود
- آدرس صفحه با History API هم‌گام می‌ماند، پس دکمهٔ «بازگشت» مرورگر درست کار می‌کند
- هنگام تایپ، پیشنهاد زندهٔ محصولات نمایش داده می‌شود
- در موبایل پنل به‌صورت کشویی از کنار باز می‌شود

## وضعیت فعلی فروشگاه شما

بررسی خروجی محصولات نشان می‌دهد:

| فیلتر | وضعیت |
|---|---|
| دسته‌بندی | ✅ کار می‌کند — ۵ دسته: کترینگ و رستورانی، آبمیوه و بستنی، فست فودی، کارتن پستی، کارتن اسباب‌کشی |
| بازهٔ قیمت | ✅ کار می‌کند — از ۱٬۶۱۵ تا ۴۲۰٬۰۰۰ تومان |
| جستجوی متنی | ✅ کار می‌کند |
| فقط موجود / فقط حراج | ✅ کار می‌کند |
| ویژگی‌ها | ⚠️ فعلاً چیزی نشان نمی‌دهد — توضیح پایین |

### چرا فیلتر ویژگی خالی است

فروشگاه یک صفت دارد: **«نوع»** با دو مقدار «یک رو» و «VIP دو رو» که روی ۱۷۴ سطر
به‌کار رفته است. ولی این صفت **محلی** تعریف شده، نه **سراسری**
(در خروجی ووکامرس، ستون «صفت ۱ سراسری» برای همهٔ سطرها `0` است).

صفت محلی داخل متای همان محصول ذخیره می‌شود و تاکسونومی ندارد؛ بنابراین نمی‌توان با
یک پرس‌وجوی کارآمد رویش فیلتر گذاشت. پنل فیلتر عمداً فقط صفت‌های سراسری (`pa_*`) را
نشان می‌دهد تا فیلتر روی فروشگاه سنگین نشود.

### ابزار تبدیل خودکار

افزونهٔ همگام‌سازی یک ابزار برای همین کار دارد:

**پیشخوان ← محصولات ← تبدیل صفت به سراسری**

ابزار همهٔ صفت‌های محلی را پیدا می‌کند، پیش‌نمایش کاملی از آنچه تغییر می‌کند نشان
می‌دهد و بعد از تأیید شما اجرا می‌شود.

```
اسکن  →  انتخاب صفت و اسلاگ لاتین  →  پیش‌نمایش  →  تأیید بکاپ  →  اجرا
```

برای «نوع»، اسلاگ پیشنهادی `type` است؛ برچسب فارسی «نوع» به‌عنوان نام نمایشی حفظ
می‌شود و چیزی در ظاهر سایت عوض نمی‌شود.

#### ابزار دقیقاً چه می‌کند

۱. صفت سراسری `pa_type` را با برچسب «نوع» می‌سازد
۲. مقادیر («یک رو»، «VIP دو رو») را به ترم تبدیل می‌کند
۳. روی هر محصول، صفت محلی را با صفت سراسری جایگزین و ترم‌ها را وصل می‌کند —
   موقعیت، نمایان بودن و «برای واریاسیون استفاده شود» حفظ می‌شوند
۴. روی هر واریاسیون، کلید صفت و **مقدارش** را به‌روز می‌کند

مرحلهٔ ۴ حساس‌ترین بخش است: واریاسیون برای صفت محلی **برچسب** («یک رو») را ذخیره
می‌کند ولی برای صفت سراسری باید **اسلاگ ترم** را ذخیره کند. اگر این تبدیل انجام
نشود، واریاسیون از والدش جدا می‌افتد و محصول قابل خرید نمی‌ماند. ابزار همه‌چیز را
از راه CRUD ووکامرس انجام می‌دهد تا خود ووکامرس این جزئیات را مدیریت کند.

#### محافظ‌ها

- **پیش‌نمایش اجباری:** تا تأیید نکنید هیچ چیزی نوشته نمی‌شود
- **تشخیص ناسازگاری:** اگر واریاسیونی مقداری داشته باشد که در فهرست مقادیر والدش
  نیست، ابزار **اجرا را رد می‌کند** و فهرست آن واریاسیون‌ها را با لینک ویرایش نشان
  می‌دهد — چون نمی‌تواند معادل درستش را حدس بزند
- **تأیید بکاپ:** بدون تیک زدن «بکاپ گرفته‌ام» دکمهٔ اجرا کار نمی‌کند

#### بعد از اجرا

به **ووکامرس ← وضعیت ← ابزارها** بروید و **«بازسازی جدول شاخص صفت‌های محصول»** را
اجرا کنید تا شمارندهٔ کنار هر گزینه در پنل فیلتر درست شود.

## ساخت ویژگی‌های قابل فیلتر

فیلتر ویژگی‌ها فقط روی **ویژگی‌های سراسری** ووکامرس کار می‌کند
(پیشخوان ← محصولات ← ویژگی‌ها). برای این فروشگاه پیشنهاد می‌شود:

| ویژگی | مقادیر نمونه |
|---|---|
| سایز | سایز ۱ … سایز ۹، کوچک، متوسط، بزرگ |
| تعداد لایه | ۳ لایه، ۵ لایه |
| نوع چاپ | ساده، چاپ‌دار |

افزونهٔ همگام‌سازی با اکسل می‌تواند این ویژگی‌ها را از ستون‌های «ویژگی: …»
به‌صورت خودکار بسازد.

## قلاب‌های توسعه

```php
// تغییر فهرست ویژگی‌های قابل فیلتر
add_filter( 'psf_filterable_attributes', function ( $taxonomies ) {
	return array( 'pa_size', 'pa_layers' );
} );

// نمایش پنل در بایگانی‌های دیگر
add_filter( 'psf_is_filterable_archive', function ( $yes ) {
	return $yes || is_post_type_archive( 'my_type' );
} );
```
