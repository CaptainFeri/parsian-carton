# بنرهای صفحهٔ اصلی

پیش از این، اسلایدر بالای صفحهٔ اصلی سه اسلاید **ثابت** بود که متنشان داخل فایل
`front-page.php` قالب نوشته شده بود؛ برای عوض کردن یک کلمه هم باید فایل قالب
ویرایش می‌شد. افزونهٔ `plugins/parsian-banners` همان اسلایدر را از پیشخوان
قابل مدیریت می‌کند.

## نصب

۱. پوشهٔ `plugins/parsian-banners` را در `wp-content/plugins/` بگذارید
   (یا `dist/parsian-banners.zip` را از پیشخوان بارگذاری کنید).
۲. پیشخوان ← افزونه‌ها ← «پارسیان کارتن — مدیریت بنرها» ← فعال‌سازی.
۳. منوی تازهٔ **بنرها** در ستون کنار پیشخوان ظاهر می‌شود.

> قالب `cartonpak` هم باید به‌روز باشد (نسخهٔ داخل `theme/`). فایل
> `front-page.php` یک خط دارد که اگر افزونه فعال بود بنرها را صدا می‌زند.
> بدون آن خط، افزونه کار می‌کند ولی باید بنرها را با شورت‌کد جای‌گذاری کنید.

## ساخت یک بنر

**بنرها ← افزودن بنر تازه**

| فیلد | توضیح |
|---|---|
| عنوان | متن درشت بنر. برای رنگی‌کردن بخشی از آن، داخل `<em>…</em>` بگذارید |
| تصویر بنر | تصویر شاخص — پس‌زمینهٔ بنر |
| برچسب بالای عنوان | متن کوتاه بالای عنوان (مثلاً «تخفیف پاییزه») |
| توضیح | یکی دو جمله زیر عنوان |
| فهرست ویژگی‌ها | هر خط یک مورد؛ روی موبایل نمایش داده نمی‌شود تا بنر کوتاه بماند |
| دکمهٔ اصلی و دوم | متن + نشانی. دکمهٔ دوم `tel:` و `mailto:` هم می‌پذیرد |
| ترتیب | در جعبهٔ «Post Attributes» — عدد کوچک‌تر، جلوتر |

و در جعبهٔ **نمایش** (ستون کناری):

| تنظیم | توضیح |
|---|---|
| جایگاه | صفحهٔ اصلی، صفحهٔ فروشگاه، یا فقط با شورت‌کد |
| روی چه دستگاهی | همه / فقط دسکتاپ / فقط موبایل |
| رنگ متن | روشن برای تصویر تیره، تیره برای تصویر روشن |
| تیرگی روی تصویر | اگر متن روی تصویر خوانا نیست، بالاترش ببرید |
| نمایش از/تا تاریخ | شمسی. هر دو خالی یعنی همیشه |
| تصویر ویژهٔ موبایل | اختیاری؛ وقتی تصویر افقی روی گوشی بد بریده می‌شود |

**روشن و خاموش کردن بنر** = همان «انتشار» و «پیش‌نویس» وردپرس. در ستون
«وضعیت» فهرست بنرها سه حالت دیده می‌شود: در حال نمایش، خارج از بازه، خاموش.

## نکتهٔ مهم: بنر بلند روی گوشی

روی صفحهٔ ۸۴۴ پیکسلی، بنر پیش‌فرض ۵۸۰ پیکسل می‌شد — ۶۹٪ صفحهٔ اول، بی‌آنکه
کاربر حتی یک محصول ببیند. افزونه روی موبایل خودش جمع می‌شود (فهرست ویژگی‌ها
پنهان، توضیح حداکثر سه خط، عنوان کوچک‌تر) و به حدود ۴۳۰ پیکسل می‌رسد.

هرچه متن بنر کوتاه‌تر باشد، بنر کوتاه‌تر است و محصولات زودتر دیده می‌شوند.
تنظیم «کمینهٔ ارتفاع» کفِ ارتفاع است، نه سقفش.

## وقتی هیچ بنری نساخته‌اید

صفحهٔ اصلی همان اسلایدر ثابت قالب را نشان می‌دهد. با ساختن نخستین بنرِ
منتشرشده، جایش را می‌گیرد. اگر می‌خواهید بالای صفحه به‌کلی خالی بماند، در
**بنرها ← تنظیمات** گزینهٔ «اسلایدر ثابت قالب نمایش داده شود» را خاموش کنید.

## گذاشتن بنر در جای دیگر

```
[parsian_banners]                      بنرهای جایگاه «فقط با شورت‌کد»
[parsian_banners location="home"]      همان بنرهای صفحهٔ اصلی
[parsian_banners location="shop"]      بنرهای صفحهٔ فروشگاه
```

## تنظیمات

**بنرها ← تنظیمات**

- **چرخش خودکار:** فاصلهٔ عوض شدن بنرها به ثانیه؛ صفر یعنی فقط دستی.
- **کمینهٔ ارتفاع دسکتاپ/موبایل**
- **وقتی بنری نیست:** اسلایدر ثابت قالب نشان داده شود یا نه.

## چرا جاوااسکریپت تازه‌ای ندارد؟

اسلایدر قالب (`assets/js/main.js`) عمومی است و روی هر `.hero-slide` کار
می‌کند. خروجی افزونه دقیقاً همان ساختار و همان نام‌های کلاس را می‌سازد، پس
چرخش، فلش‌ها و نقطه‌ها بدون یک خط کد تازه کار می‌کنند و ظاهر سایت هم عوض
نمی‌شود. تنها چیزی که افزونه اضافه می‌کند **کشیدن با انگشت** روی موبایل است.

## توسعه

```php
// افزودن یک جایگاه تازه
add_filter( 'pbn_locations', function ( $locations ) {
	$locations['blog'] = 'بالای وبلاگ';
	return $locations;
} );

// دست بردن در فهرست بنرهای نمایش‌داده‌شده
add_filter( 'pbn_active_banners', function ( $banners, $location ) {
	return $banners;
}, 10, 2 );
```

در قالب:

```php
if ( function_exists( 'parsian_banners_render' ) ) {
	parsian_banners_render( 'home' );   // true اگر چیزی چاپ شد
}
```
